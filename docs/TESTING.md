- 新增 `npm run build:email` 与 `npm run test:email`，后者对本地生产构建 Worker 使用真实 Supabase SDK 和本机 HTTP 契约服务，覆盖匿名与伪造平台身份拒绝、跨源拒绝、密码长度与邮箱允许列表、注册验证、一次性链接及站外跳转防护、HttpOnly cookie、会话自动续期、真实 D1 双邮箱数据隔离、密码重置及退出。

## 尚需线上与设备验证
